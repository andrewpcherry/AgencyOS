How to Build a Campaign — Step by Step
You'll get a Task in the Tasks app telling you to build a campaign. Here's the exact sequence:
Step 1 — Open the Campaign Record
Go to Campaigns app → Build Queue view.
Find the campaign assigned to you (Status = Draft).
Open the record.
Step 2 — Confirm the Setup Info
Check these fields are filled in BEFORE you touch Ads Manager:
Client — correct client is linked
Market — geographic market is listed
Campaign Type — Video Views / Retarget / Lead Ad
Daily Budget — dollar amount is set
Script Link — Google Drive link to the video script
Asset Link — Google Drive link to the video file
Week — which week of the quarter (W1–W13)
Step 3 — Get the Video
Click the Asset Link to open Google Drive.
Download the video file.
Confirm it matches the Script Link / script ID.
Step 4 — Build in Ads Manager
Find the client's Ad Account ID in the Clients app (Ad Acct ID field). Log into their Facebook Ads Manager via their Business Portfolio.
Create the campaign using the naming convention above.
Set the campaign objective:
Video Views → Video Views objective
Retarget → Engagement objective
Lead Ad → Leads objective (uses Facebook Lead Form)
Set the audience:
Video Views → broad audience (state or major metro, no custom audiences)
Retarget → use the 25% / 50% video viewer custom audiences (auto-built — confirm they exist before proceeding)
Lead Ad → use the 75% / 95% video viewer custom audiences (also auto-built from Video Views activity)
Set the budget to match the Daily Budget field.
Upload the video.
Set the CTA based on campaign type:
Video Views → No CTA button. Ad copy tells viewers to comment "OPTIONS" — drives engagement, builds the retargeting pool.
Retarget → No CTA button. Same approach. Different video, same "comment OPTIONS" CTA.
Lead Ad → Facebook Lead Form attached. This is the only campaign that captures contact details.
Do NOT use zip code targeting. City/state level only — Facebook Housing rules.
Turn CBO (Campaign Budget Optimisation) OFF.
Save as draft in Ads Manager. Do NOT publish yet — QA first.
Step 5 — Fill in the Campaign Record
Back in SmartSuite, update the campaign record:
Campaign Name → paste the exact campaign name from Ads Manager
Ad Set Name → paste the exact ad set name
Ad Name → paste the exact ad name
Platform Campaign ID → the Facebook Campaign ID (in Ads Manager URL or settings)
Owner → set to your name (VA / Operator)
Status → change from Draft to QA Ready

Step 6 — Complete the QA Checklist
Tick each QA field in the record. Only tick Yes when you have personally confirmed it.
Step 7 — Publish and Update
Once all 9 QA checks are Yes, publish the campaign in Ads Manager.
In the SmartSuite record, change Status to Live.
Set Launch Date to today's date.
Tick Client Launch Notified → Yes (n8n sends the notification, but confirm it happened).
Mark your Task in the Tasks app as Done.

How Metrics Work — Automatic
You don't enter metrics. Windsor AI pulls performance data from Facebook every 12 hours and n8n writes it into the campaign record.
Fields populated automatically:
Spend, ThruPlays, Cost / ThruPlay
50% Views, 75% Views, 95% Views
Saves, Shares, Comments, DMs
Leads, Cost / Lead
Last Pull Date — shows when data was last synced

What NOT to Do
Never skip Special Ad Category = Housing. Legal requirement. Skipping risks an ad account ban.
Never use zip code targeting. Facebook's housing rules prohibit it. City/state only.
Never publish without all 9 QA checks ticked Yes.
Never change the Platform Campaign ID once set. Windsor uses it to pull metrics.
Never mark Status = Live unless the campaign is actually published and running.
Never leave Asset Link or Script Link blank. If you can't find the file, ask Andrew before building.

Each Campaigns record = one Facebook campaign. You build it in Ads Manager and mirror the setup in the SmartSuite record. Windsor AI pulls metrics in automatically.
Every client runs 3 campaign types stacked: Video Views (cold) → Retarget (warm, auto-built audiences) → Lead Ad (hot, captures leads via FB Lead Form).

Type | Audience | Goal
Video Views | Cold — broad audience, no prior interaction | Get videos in front of distressed sellers. Build the retargeting pool.
Retarget | Warm — people who watched 25%+ of a Video Views ad | Different talking-head video, same "comment OPTIONS" CTA. Push viewers toward 75%+ for the Lead Ad.
Lead Ad | Hot — people who watched 75%+ or engaged with content | Capture contact details via Facebook Lead Form. The ONLY campaign that collects leads.
 | Audiences auto-build
Retarget and Lead Ad audiences are built automatically from Video Views activity by the Campaign Intelligence Agent. They are NOT created manually during onboarding. If they don't exist yet, the Video Views campaign hasn't run long enough — flag to Andrew, do not proceed.
